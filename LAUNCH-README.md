# Menscents — Public launch candidate

## What is included
- Rebuilt responsive editorial homepage and all shared navigation and footers
- Eight completely rewritten research-led fragrance profiles
- Five rewritten occasion guides
- Three rewritten comparisons and alternatives overview
- Three original educational journal articles
- Interactive browser-only scent finder and searchable fragrance index
- About, methodology, affiliate disclosure, privacy, sitemap, robots, custom 404
- Locally bundled CSS, JavaScript and illustrative editorial imagery; no external font or analytics requests

## Editorial truthfulness
All fragrance images are illustrative editorial photography, **not genuine photos of the named products**. Product pages label this explicitly. The site does not claim hands-on testing, verified wear time, actual prices or live retailer availability. Amazon search-result affiliate links are present with the tag bnsn-20; individual ASINs and sellers have NOT been verified.
